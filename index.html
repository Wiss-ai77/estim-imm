    Méthode et limites

    • Source des prix : « Demandes de valeurs foncières géolocalisées » (DGFiP / Etalab), c'est-à-dire toutes les ventes enregistrées chez les notaires, publiées deux fois par an avec environ 6 mois de retard. Le site télécharge directement les fichiers de la commune concernée depuis files.data.gouv.fr ; rien ne transite par un serveur tiers.
    • Nettoyage : ventes classiques uniquement (pas de VEFA, échanges, adjudications), un seul logement par transaction (les ventes en bloc, les mélanges maison + appartement et les locaux commerciaux sont exclus), prix au m² entre 500 et 25 000 €. La surface utilisée est la surface réelle bâtie.
    • Statistique : la médiane (moins sensible aux extrêmes que la moyenne) sur les ventes situées dans le rayon choisi, et la fourchette P25–P75. Moins de 8 ventes : le résultat est signalé comme fragile.
    • DPE : la médiane DVF mélange toutes les classes énergétiques ; on la considère comme représentative d'un bien de classe D (le cas le plus fréquent dans l'ancien) et on applique les écarts mesurés par les Notaires de France sur les transactions 2024 (étude « valeur verte », déc. 2025). En Île-de-France les écarts sont plus faibles qu'en province : environ +4 % pour un A-B et −5 % pour un F-G en petite couronne sur les appartements ; jusqu'à +17 % (A) et −25 % (G) sur les maisons au niveau national.
    • Ce que ça ne voit pas : l'état intérieur, l'étage, l'exposition, un jardin exceptionnel, la copropriété, et les ventes des 6 à 12 derniers mois. C'est un ordre de grandeur pour préparer une négociation, pas une expertise. Hors périmètre : Alsace, Moselle, Mayotte (pas de DVF).

    Sources : DVF géolocalisées (data.gouv.fr) · API Adresse · Notaires de France, « La valeur verte des logements », transactions 2024. Code source sur GitHub (lien dans le pied de page).
